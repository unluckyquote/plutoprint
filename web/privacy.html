Privacy

This installer page collects nothing about you. It sets no cookies, runs no analytics and sends nothing to its author.

Hosting

The page is hosted on GitHub Pages. GitHub receives your IP address and browser details when you open it, as any web host does, and handles them under the GitHub Privacy Statement. That is the only service this page contacts.

Libraries

The page uses ESP Web Tools (to install the firmware) and three.js (for the case viewer). Both are served from this same site, not from a content delivery network, so opening the page doesn't send your address to anyone else.

Your ESP32 and printer

The install happens between your browser and the ESP32 over USB. The WiFi name and password you enter go straight from your browser to the ESP32 and are stored only on it. The ESP32 doesn't contact any server of mine or anyone else's. Everything stays on your network.

Links that leave this page

The links to Amazon NL (parts that I used) and GitHub only load if you click them, and they aren't affiliate links. Those sites then have their own privacy policies.
